网站与数据库

管理员可管理学生、课程、成绩和缴费。学生可查看自己的档案、电话、地址、GPA、课程学分和未缴余额。

网站源码：website/
实际数据库：website/db.sqlite3
干净快照：database/studenthub-demo.sqlite3
SQL 转储：database/studenthub-demo.sql

SQL 文件是 SQLite 格式，不是 MySQL 导入文件。数据库已包含虚构学生、课程、成绩、费用及考勤。

需要重新创建数据库时

在项目文件夹打开 PowerShell，使用包内运行环境：

.\runtime\python.exe .\website\manage.py migrate --noinput
.\runtime\python.exe .\website\manage.py seed_part_a

不要使用上游的 seed_demo。已提供修正后的 seed_part_a；重复执行不会重置现有密码或覆盖已改资料。

故障排查

启动失败查看 logs/startup-error.log 和 logs/server.stderr.log。8000 端口被其他程序占用时，按 README 的手动运行方式更换端口。移动文件夹前先停止网站。

这是保留已知弱点的本地教学版本，只使用虚构资料。原系统的完整联系人编辑、独立教师权限和完整学分核算不在本次 A 部分交付中。
